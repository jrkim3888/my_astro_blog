## 한 줄 요약: 아스트라와 대등한데 토큰 단가는 10분의 1

가장 눈에 띄는 주장은 컴퓨터 사용 벤치마크에서 나왔습니다. **GPT-6 Astra와 대등한 성능을 내면서 토큰당 가격은 10분의 1**이라는 것입니다.

실제로 가격표를 보면 Astra가 100만 토큰당 $10/$50이고 Terra는 $1/$5이니, 단가는 정확히 10분의 1이 맞습니다. 문제는 "대등한 성능"이 어디까지 적용되는 말이냐인데, 이 부분은 뒤에서 따로 짚겠습니다.

<br/>

## 핵심 사양

| 항목 | 내용 |
|------|------|
| 모델 ID | `gpt-6.1-terra` |
| 컨텍스트 윈도우 | 1,050,000 토큰 |
| 최대 출력 | 128,000 토큰 |
| 입력 형식 | 텍스트, 이미지 |
| 출력 형식 | 텍스트 |
| 추론 강도 | None / Low / **Medium(기본)** / High / Xhigh / Max |
| 컴퓨터 사용 | Responses API의 호스팅 도구로 제공 |
| 파인튜닝 | 출시 시점 미지원 |

추론 강도가 6단계로 나뉘어 있다는 점이 중요합니다. 뒤에 나오는 벤치마크 수치가 **어느 추론 강도에서 측정한 것인지에 따라 크게 달라지기 때문**입니다.

## 가격: 이 모델의 존재 이유

| 항목 | 100만 토큰당 |
|------|-------------|
| 입력 | $1 |
| 캐시된 입력 | $0.05 |
| 출력 | $5 |

- **GPT-5.6 Terra와 GPT-6.1 Sol 대비 50% 인하** — Sol이 $2/$10이니 정확히 절반입니다
- **Batch·Flex**: 표준 요금보다 50% 더 저렴 (비동기 작업용)
- **Fast 모드**: 표준 요금의 2배
- **272K 토큰 초과 입력**: 요청 전체에 입력·캐시 2배, 출력 1.5배 할증

캐시된 입력이 $0.05까지 내려간 점이 눈에 띕니다. 같은 문서를 반복해서 읽는 업무 자동화에서는 실제 체감 비용이 표시 가격보다 훨씬 낮아질 수 있습니다.

## 공식 벤치마크

OpenAI가 공개한 차트는 모두 **가로축이 비용, 세로축이 점수인 산점도**입니다. 점수만 비교하는 막대그래프가 아니라 비용 축을 전면에 놓았다는 것부터가 이 모델의 성격을 드러냅니다. 같은 모델의 점들이 선으로 이어진 것은 추론 강도를 올려가며 측정한 결과입니다.

## 환각 감소: 이번 발표에서 가장 큰 폭의 개선

오류를 유발하도록 설계된 내부 벤치마크 기준입니다.

| 추론 강도 | GPT-5.6 Terra | GPT-6.1 Terra |
|-----------|---------------|---------------|
| 낮음 | 53.6% | **16.7%** (약 37%p 감소) |
| 최대 | — | **4.3%** (18%p 감소) |

![어려운 프롬프트에 대한 사실 오류율 비교](/images/blog/2026-10-29-gpt-6-1-terra-release_4.png)

*이미지 출처: [OpenAI 공식 블로그](https://openai.com/ko-KR/index/introducing-gpt-6-1-terra/)*

이 차트는 세로축이 **낮을수록 좋은** 지표(사실 오류가 하나라도 포함된 답변 비율)라 다른 차트와 반대로 읽어야 합니다. 두 Terra의 곡선이 완전히 분리되어 있는데, 이전 Terra가 가장 좋은 조건에서 도달한 22% 수준을 **새 Terra는 가장 싼 조건에서 이미 16.7%로 시작**합니다.

추론 강도 Max에서의 4.3%는 **Astra·Sol과 거의 같은 수준**입니다. 저가 모델이 최상위 모델급 사실 정확성에 도달했다는 뜻이라 의미가 작지 않습니다.

다만 **낮은 추론 강도에서는 여전히 16.7%** 입니다. 비용을 아끼려고 추론 강도를 낮추면 그만큼 사실 오류 위험이 올라간다는 뜻이고, 이 모델의 세일즈 포인트가 "싸게 많이 돌리기"라는 점을 생각하면 짚어둘 지점입니다.

## 독립 평가: Artificial Analysis

벤더 자체 수치만으로는 판단이 어려우니 외부 집계도 함께 봅니다.

- **지능지수(AAII)**: 추론 Max에서 이전 Terra 대비 **6점 상승**. 작업당 비용은 **$1.40 → $0.40으로 약 71% 감소**. Sol과의 점수 차는 **4점**
- **코딩 에이전트 지수 2.0**: Terra **48점** — Sol(54점)보다 6점 낮고, Luna(31점)보다 17점 높음
- **AA-Omniscience(환각)**: 모르는 질문에 추측으로 답한 비율이 **88% → 38%** 로 50%p 감소, 정답률은 2%p 상승

점수 차는 Sol 대비 4~6점인데 비용은 절반 이하라는 구도가 반복됩니다. **절대 성능에서는 지고, 비용 대비 성능에서는 이기는** 전형적인 중급 모델 포지션입니다.

Plotly가 합성 풍력 발전 데이터로 만든 비공개 43문항 시험 결과입니다.

| 총점(43문항) | 38 | **40** | 43 |
| 숨겨진 패턴(5문항) | 2 | **3** | 5 |
| 통계 함정(5문항) | 3 | **4** | 5 |

| 1인당 연간 비용 환산 | $7.50 | **$76** | $152 |

기본 분석, 모호한 질문 식별, 불가능한 요청 거르기, 데이터 품질 문제 발견은 **세 모델 모두 만점**이었습니다. 차이는 **어려운 문항에서만** 났습니다. 숨겨진 패턴 5개 중 Luna 2개, Terra 3개, Sol 5개입니다.

Terra는 Luna보다 2문항 더 맞히며 연 $68를 더 쓰고, Sol보다 3문항 덜 맞히며 연 $76를 아끼는 위치입니다. 응답 속도는 셋 중 가장 빨랐습니다.

다만 이 시험은 Plotly가 자사 분석 제품을 파는 회사라는 점, 시험이 비공개라 재현 검증이 어렵다는 점, 합성 데이터와 단일 설정으로만 돌렸다는 점을 감안해야 합니다.

## 안전성

- OpenAI 준비성 평가 프레임워크에서 **사이버보안 '심각(Critical)' 임계치에 도달**했고, Astra용으로 만든 보호 조치를 그대로 유지합니다
- GPT-6 시리즈의 정렬 개선이 적용되어, 범위를 벗어나지 않고 한계를 솔직히 알릴 가능성이 이전 Terra보다 높아졌습니다
- 프롬프트 인젝션 테스트에서 작업 이탈을 유도하는 악의적 지시에 강한 저항을 보였습니다

저가 모델이 사이버보안 Critical 임계치에 도달했다는 점은 눈여겨볼 만합니다. [아르곤 포스팅](/blog/2026-10-06-gemini-4-argon-release)에서 정리했듯, 보안 능력이 임계점을 넘으면 공개 방식 자체가 제품 설계의 일부가 되는 흐름이 이어지고 있습니다.

## 한계와 유의점

- **수치 대부분이 자체 측정입니다.** Agents' Last Exam, 환각 벤치마크, MMMU-Pro 비교는 모두 OpenAI 내부 평가 기준이고, 출시 직후라 독립 재현 검증은 아직 없습니다
- **복잡한 코딩은 권장 대상이 아닙니다.** OpenAI가 직접 Sol·Astra를 권했고, AA 코딩 지수에서도 Sol에 6점 뒤집니다
- **"Astra와 대등"은 컴퓨터 사용 벤치마크 한정**입니다. 전 영역에서 대등하다는 뜻이 아닙니다
- **추측 응답 38%가 남아 있습니다.** 88%에서 크게 줄었지만 여전히 모르는 질문의 3분의 1 이상에 추측으로 답합니다
- **저추론 설정의 오류율 16.7%** — 비용 최적화와 정확도가 정면으로 맞바뀝니다
- **절대 점수 1위는 Claude인 경우가 많습니다.** OpenAI가 직접 공개한 차트에서도 Terminal-Bench 4.0과 OSWorld 2.1의 최고 점수는 Claude Sonnet 5.5, Agents' Last Exam의 최고 점수는 Claude Opus 5.5입니다. Terra의 강점은 어디까지나 **같은 점수를 훨씬 싸게 낸다는 것**이지 점수 자체가 아닙니다

## 개발자에게 의미하는 바

### 1. 모델 선택 기준이 "성능"에서 "작업당 비용"으로

Terra의 수치는 대부분 점수가 아니라 **점수 대비 비용**으로 제시됩니다. 벤치마크 1등을 고르는 게 아니라, **이 작업에 필요한 최소 성능이 어디까지인지 정하고 거기서 가장 싼 것을 고르는** 방식이 기본값이 되어가고 있습니다.

### 2. 추론 강도를 설계 변수로 다뤄야 한다

같은 모델인데 저추론에서 오류율 16.7%, Max에서 4.3%입니다. **모델을 고르는 것만큼 추론 강도를 고르는 것이 중요**해졌고, 작업 성격에 따라 단계를 나누는 설계가 필요합니다. 틀리면 손해가 큰 작업은 Max로, 대량 단순 처리는 낮게 가는 식입니다.

### 3. 대량 반복 작업의 손익분기가 내려간다

캐시 입력 $0.05에 Batch 50% 추가 할인까지 적용하면, 그동안 "AI로 돌리기엔 단가가 안 맞던" 업무들이 계산상 가능해집니다. 청구서 읽어 회계 시스템에 입력하기 같은 작업이 공식 발표의 대표 예시로 등장한 것도 같은 맥락입니다.

<br/>

## 결론

GPT-6.1 Terra는 성능 경쟁의 모델이 아니라 **가격 경쟁의 모델**입니다. 절대 성능은 Sol·Astra에 못 미치지만, 작업당 비용에서 9분의 1까지 벌리면서 컴퓨터 사용과 사실 정확성은 최상위권에 근접시켰습니다.

주의할 점은 "Astra급"이라는 표현이 **컴퓨터 사용 벤치마크에 한정된 이야기**라는 것, 그리고 핵심 수치 대부분이 아직 벤더 자체 측정이라는 것입니다. 저추론 설정에서의 오류율 16.7%도 비용 최적화를 염두에 둔다면 미리 측정해볼 값입니다.

### 핵심 정리
1. **포지션**: 최고 성능이 아니라 비용 대비 성능을 노린 중급 모델, 10월 26일 공개
2. **가격**: $1/$5(캐시 $0.05)로 Sol·이전 Terra 대비 50% 인하, Astra 단가의 10분의 1
3. **컴퓨터 사용**: Agents' Last Exam에서 Astra와 대등하며 속도는 3배 이상
4. **환각**: 저추론 53.6% → 16.7%, Max에서는 4.3%로 Astra·Sol 수준
5. **독립 평가**: AA 지능지수 Sol과 4점 차, 코딩 지수는 48점으로 Sol(54)에 뒤짐
6. **사양**: 컨텍스트 105만 토큰, 출력 12.8만, 추론 강도 6단계
7. **이용**: Plus·Pro·Enterprise·Edu의 ChatGPT Work와 Codex, API는 `gpt-6.1-terra`
